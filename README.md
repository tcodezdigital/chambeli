# Chambeli Institute homepage

## Open locally
Open index.html in a browser. Keep the assets directory beside it.

## GitHub and Vercel
Upload index.html and assets/ to the repository root. Import the repository into Vercel. Select the Other framework preset. No build command or dependency installation is required. Serve the repository root.

## Contents
HTML, inline CSS and JavaScript, responsive navigation, FAQs, structured organization data, local logo and institute photos. No external fonts, JavaScript libraries, tracking, payment processing or form backend.

## Before replacing WordPress
This is the homepage only. Program, administration, gallery, about and donation links currently target existing chambeli.org paths. Build these pages at the same paths before moving the domain, or update the links. Confirm contact details, service availability, registration information and photo publication permissions. Do not retire WordPress until all remaining pages and URL redirects are ready.

## Content and assets
Logo supplied by the user. Four photographs downloaded from the existing site's /wp-content/uploads/2020/02/slide1.jpg through slide4.jpg. Content drawn from published About, School, Departments, Rehabilitation, Vocational Training, Donate and Contact pages. No invented impact statistics, testimonials or current child sponsorship profiles.

## Verification
Confirmed all five local image assets open and all local image references and in-page link targets exist. Automated browser layout testing was unavailable because this environment lacks a Chromium executable. Please preview at desktop and phone widths before launch.
